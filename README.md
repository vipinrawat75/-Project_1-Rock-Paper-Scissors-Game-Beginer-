# -Project_1-Rock-Paper-Scissors-Game-Beginer-
A beginner-friendly Python project that lets you play Rock, Paper, Scissors against the computer. Built using basic Python concepts like conditionals, loops, and the random module. Great for learning user input handling and simple game logic.

This is a simple Python project where you can play Rock, Paper, Scissors against the computer. The computer makes a random choice, and your goal is to beat it!

## 💻 Features
- Text-based interface
- Random computer choices
- Score tracking (optional)
- Simple game loop with replay option

## 🧠 Concepts Used
- Conditional statements (`if`, `elif`, `else`)
- Loops
- User input
- Python’s `random` module

## ▶️ How to Run
1. Make sure you have Python installed
2. Run the script:
```bash
python rock_paper_scissors.py
